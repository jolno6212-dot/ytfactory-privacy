ytfactory

ytfactory は、運営者が持つ自分の YouTube チャンネル（現在は「くらべて研究所」@kurabete-lab と @icchi-nichijo の2つ。チャンネル名は変わることがあります）に、運営者が自分で制作した動画をアップロードするための個人用コマンドラインツールです。YouTube API Services を利用しています。

ytfactory is a private command-line tool that the owner uses to upload their own videos to the owner's own YouTube channels (currently two: "Kurabete Lab" @kurabete-lab and @icchi-nichijo; channel names may change). It uses YouTube API Services.

主な機能 / Features

  • 動画ファイル・タイトル・概要欄・タグのアップロード（videos.insert） / Upload a video with title, description and tags
  • サムネイルの設定（thumbnails.set） / Set the thumbnail
  • 公開設定・公開予約 / Set privacy status or scheduled publish time
  • アップロード済み動画の確認（channels.list, videos.list） / Check uploaded videos

他のユーザーには提供していません。視聴者や他のチャンネルのデータは扱いません。
It is not offered to other users and does not handle data of viewers or other channels.
